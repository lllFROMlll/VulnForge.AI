Instruções permanentes de trabalho para qualquer agente nesta sessão/projeto.

## Fluxo de trabalho obrigatório (planejar primeiro, criar só após aprovação explícita)

1. Sempre **conversar/planejar primeiro**, resolvendo TODAS as questões antes de qualquer ação.
2. Somente depois de tudo resolvido, **perguntar ao usuário se pode criar/implementar**.
3. Nenhuma ação que afete o projeto (criar, corrigir, modificar, remover, sobrescrever arquivos/código, compilar/instalar APK, executar comandos mutantes como git add/commit/push/gradle) pode ser executada sem a **APROVAÇÃO EXPLÍTICA** do usuário.
4. Aguardar a confirmação antes de implementar qualquer coisa.
5. "Perguntar se há como corrigir" **NÃO** é autorização para corrigir.
